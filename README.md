Pegasus Lacak Ultimate adalah toolkit OSINT (Open Source Intelligence) yang dirancang untuk investigasi digital dan pengumpulan informasi dari berbagai sumber. Tool ini membantu investigator dan peneliti keamanan dalam menganalisis data secara efisien.

## Fitur Utama

- **Phone Tracking**: Analisis nomor telepon, identifikasi provider, dan geolokasi.
- **WhatsApp Analysis**: Monitor status online, analisis profil, dan export riwayat chat.
- **Email Investigation**: Verifikasi email, pencarian kebocoran data, dan analisis domain.
- **NIK/KTP Scanner**: Validasi nomor KTP dan verifikasi data demografis.
- **IP & Website Analysis**: Geolokasi IP, DNS reconnaissance, dan website scanning.

## Instalasi

1. Clone repository:
   ```bash
   git clone https://github.com/sobri3195/pegasus-lacak-ultimate.git
   cd pegasus-lacak-ultimate
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Jalankan program:
   ```bash
   python pegasus_lacak_ultimate.py
   ```

## Persyaratan

- Python 3.8 atau lebih baru
- Sistem operasi Linux/Unix
- Koneksi internet
- Minimal RAM 4GB

## Penggunaan

1. Jalankan program.
2. Pilih menu yang tersedia:
   - NIK Scanner
   - Phone Analysis
   - Email Investigation
   - IP Analysis
   - Social Media Analysis
   - Dark Web Scan
   - Web Recon
3. Ikuti instruksi di layar.
4. Hasil akan disimpan di folder `output`.
